# 워크스캔 활용 개선 (hello-hello)

> CJ푸드빌 사내 직원 근태 관리를 워크스캔으로 더 효과적으로 하기 위한 프로젝트

## 소개

CJ푸드빌은 직원 근태 관리에 워크스캔을 쓰고 있습니다. 하지만 지금은 주로 출퇴근 지문 인식에만 쓰고, 그 밖의 근태 관리는 여전히 수기로 처리하는 경우가 많습니다.

수기 관리는 시간이 많이 들고 실수가 생기기 쉽습니다. 이 프로젝트는 워크스캔이 이미 제공하는 기능을 더 넓게 활용해서 근태 관리와 관련 인사 업무를 디지털로 정리하는 것을 목표로 합니다.

## 한눈에 보기

- **포트폴리오 사례 페이지**: https://claude.ai/artifact/LLnyTqZ38JW79aUtDWTaFB
- **클릭 가능한 와이어프레임 (S1~S7)**: https://claude.ai/artifact/8VcacdESZg8mKSicw4GsTw

두 링크 모두 가상 데이터로 만든 제안 화면입니다. 공유 설정을 켜야 다른 사람이 열 수 있습니다.

## 문제 정의

- 근태 기록, 근무 일정 조정 등을 수기로 관리해서 비효율적이다.
- 워크스캔을 지문 출퇴근 기록 위주로만 쓰고 있다.
- 근로계약서와 급여명세서가 근태 기록과 따로 관리된다.

## 주요 기능 (목표)

- **근태 관리**: 출퇴근 기록, 지각·조퇴·결근 확인, 근무 일정 관리
- **근로계약서 작성**: 전자 근로계약서 작성과 보관
- **급여명세서 관리**: 근태 기록을 바탕으로 급여명세서 발급과 조회
- **수기 업무 줄이기**: 지금 손으로 처리하는 근태 업무를 찾아서 워크스캔 기능으로 대체

## 진행 계획

1. 현재 수기로 처리하는 근태 업무 정리
2. 워크스캔 기능 중 아직 쓰지 않는 기능 조사
3. 업무별로 워크스캔 활용 방안 제안
4. 적용 후 효과 비교 (처리 시간, 오류 건수 등)

## 기술 스택

코딩 없음. 문서 중심 프로젝트입니다 (최종 결과물: 매장용 워크스캔 사용 가이드).

## 시작하기


## 주의 사항

근로계약서, 급여명세서, 근태 기록에는 직원 개인정보가 들어 있습니다. 실제 직원 데이터나 회사 내부 자료는 이 저장소에 올리지 말고, 필요하면 가상의 예시 데이터를 사용하세요.
