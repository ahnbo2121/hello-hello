# 와이어프레임 사용성 휴리스틱 점검

[클릭 가능한 와이어프레임](https://claude.ai/artifact/8VcacdESZg8mKSicw4GsTw)(S1~S7, 버전 2)을 세 가지 방법으로 점검했습니다. 심각도 3인 U1~U4는 버전 3에 반영했습니다(아래 "반영 결과").

1. **닐슨의 10가지 사용성 휴리스틱**
2. **현장 기준**: 매장 근무 환경에서 나온 기준
3. **인지적 워크스루**: 4명 페르소나가 각자 과업을 끝까지 해 보기

> **점검 방식과 한계**: 와이어프레임을 만든 쪽(작성자와 Claude)이 화면 구성과 동작을 기준으로 점검했습니다. 실제 사용자 테스트가 아니므로, 여기서 찾은 문제는 "가능성이 높은 문제"입니다. 실제 스텝·매니저에게 보여 주면 다른 문제가 더 나올 수 있습니다.
>
> 와이어프레임 링크는 현재 작성자만 열 수 있습니다. 다른 사람에게 보여 주려면 페이지의 Share 메뉴에서 공유해야 합니다.

## 심각도 기준 (닐슨 0~4)

| 점수 | 뜻 |
|---|---|
| 4 | 치명적: 과업을 끝낼 수 없음. 반드시 고쳐야 함 |
| 3 | 큼: 잘못된 기록이 남거나 큰 혼란. 우선 고쳐야 함 |
| 2 | 보통: 불편하거나 되돌리기 어려움. 고치면 좋음 |

| 0 | 문제 아님 |
