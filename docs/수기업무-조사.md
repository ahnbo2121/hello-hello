# 수기 근태 업무 조사

진행 계획 1단계: 지금 손으로 처리하는 근태·인사 업무를 정리합니다.

> **개인정보 주의**: 직원 이름, 사번, 급여액, 연락처 같은 실제 데이터는 적지 마세요. 업무 내용과 처리 방식만 적습니다. 예시가 필요하면 "직원 A"처럼 가상의 이름을 쓰세요.

## 작성 방법

1. 아래 요약 표에 업무를 한 줄씩 추가합니다.
2. 시간이 많이 걸리거나 실수가 잦은 업무는 아래 "업무 상세"에 따로 적습니다.
3. "워크스캔으로 대체 가능?" 칸은 2단계(기능 조사)를 마친 뒤 채웁니다.

| 칸 | 적을 내용 |
|---|---|
| 처리 방식 | 종이, 엑셀, 카톡, 전화 등 |
| 담당 | 점장, 매니저, 본사 인사팀 등 역할 (실명 X) |
| 빈도 | 매일 / 매주 / 매월 / 발생할 때마다 |

| 워크스캔으로 대체 가능? | 예 / 일부 / 아니오 / 확인 필요 |
