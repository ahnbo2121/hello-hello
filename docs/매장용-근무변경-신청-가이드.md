# 근무 변경 앱 신청 가이드 (매장용)

> 근무시간이 바뀌면 종이 동의서 대신 **앱에서 신청하고 승인**합니다. 지문 출퇴근은 지금처럼 그대로 찍습니다.

| 대상 | 볼 곳 |
|---|---|
| 스텝 | 1~3 |
| 점장·승인자 | 4 |
| 인턴매니저 | 5 |

> **이 가이드의 위치**: [개선안](개선안-스케줄변경-전자결재.md)을 도입한다고 가정하고, [와이어프레임](https://claude.ai/artifact/8VcacdESZg8mKSicw4GsTw)의 제안 화면(S1~S6)을 기준으로 쓴 **초안**입니다. 워크스캔 실제 화면이 아니므로 메뉴 이름과 동작은 도입할 때 맞춰 고쳐야 합니다(맨 아래 "배포 전 확인").

---

## 왜 바꾸나요?

- 지금은 같은 변경을 **동의서, 근무표 손글씨, 카톡**에 여러 번 적습니다.
- 연장시간을 직접 계산해 적다 보면 실제 시각과 맞지 않는 경우가 생깁니다.
- 점장 확인 칸이 비어 있으면, 연장근무를 누가 승인했는지 근거가 남지 않습니다.
- 앱으로 신청하면 **시간은 자동 계산**되고, **승인 기록이 자동으로 남습니다.** 내 연장수당의 근거가 됩니다.

---

## 1. 근무시간이 바뀌었을 때 (스텝)

1. 앱에서 **근무 변경 신청**을 엽니다. 오늘 내 계획 근무시간이 위에 보입니다.
2. **사유**를 고릅니다. 사유에 따라 바꾸는 시각이 달라집니다.

   | 사유 | 바꾸는 것 | 앱이 계산해 주는 것 |
   |---|---|---|
   | 연장근무 | 퇴근 시각 | 연장시간 |
   | 조기퇴근 | 퇴근 시각 (앞당기기) | 단축시간 |
   | 지각 | 출근 시각 | 지각 시간 |
   | 사전협의 변경 | 출근·퇴근 시각 둘 다 | 변경 후 근무시간 |
   | 결근 | 시각 없음 | 사유만 기록 |
   | 신규입사 | 첫 근무 출근·퇴근 시각 | 근무시간 |

3. **시각**을 맞춥니다. 자주 쓰는 시각 버튼을 누르거나, **±5분·±30분** 버튼으로 실제 시각에 맞춥니다. 마감 직후라면 **지금 퇴근** 버튼을 누릅니다.
4. 계산된 시간을 확인하고, **동의**에 체크한 뒤 **신청하기**를 누릅니다.

✅ 신청하면 승인자에게 알림이 갑니다. 연장시간을 직접 계산하거나 종이에 쓰지 않아도 됩니다.

⚠️ 신청이 안 눌리면 버튼 위 안내를 보세요. 예: "조기퇴근은 계획 퇴근보다 빨라야 합니다" → 사유를 다시 고르세요.

## 2. 신청 결과 확인 (스텝)

**내 신청 현황**에서 상태를 봅니다.

| 상태 | 뜻 | 할 일 |
|---|---|---|
| 신청됨 / 미승인 | 승인 전 | 기다리기. 잘못 냈다면 **신청 취소** |
| 승인됨 | 승인자와 승인 시각이 기록됨 | 없음 |
| 반려됨 | 반려 사유가 함께 보임 | **수정해서 다시 신청** (이전 내용이 채워져 있음) |

## 3. 휴대폰이 없거나 앱을 못 쓸 때 (스텝)

- 그날 바로 **인턴매니저나 점장에게** 이름, 실제 시각, 사유를 말합니다.
- 인턴매니저가 대신 신청합니다. 다음 출근 때 **내 신청 현황**에서 "내용이 맞습니다"를 눌러 확인합니다.

---

## 4. 승인하기 (점장·승인자)

1. 영업 중 **승인 요청 알림**을 누르면 신청자, 사유, 변경 시각, 계산된 시간이 보입니다.
2. 맞으면 **승인**. 승인자와 시각이 자동으로 기록됩니다.
3. 잘못 눌렀다면 바로 뜨는 **되돌리기**를 누릅니다.
4. 반려할 때는 **사유를 먼저 고른 뒤** 반려합니다. 신청자에게 사유가 함께 갑니다.
5. 마감 무렵 **미승인 목록**에서 놓친 건을 골라 **일괄 승인**합니다.

💡 미승인이 남아 있으면 인턴매니저가 그날 근태를 마감하기 어렵습니다. 마감 전에 미승인 0건을 목표로 합니다.

## 5. 밤 근태 대조 (인턴매니저)

1. **일일 근태 대조**를 열면 직원마다 계획, 지문, 승인된 신청, 제안 인정시간, 상태가 한 줄에 보입니다.
2. **일치**하는 줄은 "한 번에 확정"을 누릅니다.
3. **시각 차이** 줄은 신청(또는 계획) 시각과 지문 시각 중 하나를 고릅니다. 잘못 골랐다면 **다시 선택**.
4. **지문 누락** 줄은 "누락 처리"에서 근거 후보를 고르고 누락 사유를 선택합니다.
5. 신청 없이 늦게 퇴근한 직원은 **대리 신청**으로 대신 입력합니다. 직원이 다음 출근 때 확인합니다.
6. **미승인** 줄은 승인자에게 다시 알리고, 그래도 처리되지 않으면 **다음 날로 넘기기**를 눌러 기록을 남깁니다.
7. 화면 아래 "마감을 막는 줄"이 0건이 되면 **일마감**합니다.

## 자주 묻는 질문

**Q. 지문은 계속 찍나요?**
A. 네. 이 가이드는 근무 변경 신청만 앱으로 옮깁니다. 출퇴근은 지금처럼 지문으로 찍습니다.

**Q. 종이 동의서는 이제 안 쓰나요?**
A. 시범 기간에는 종이와 앱을 함께 씁니다. 앱 기록이 동의 근거로 인정되는지 회사가 확인한 뒤 종이를 줄입니다.

**Q. 카톡 일일보고는요?**
A. 시범 기간에는 근무 변경·연장 내용을 카톡에 다시 쓰지 않고 앱 신청으로 대신하는 방안을 검토합니다. 나머지 보고는 그대로입니다.

**Q. 연장시간이 30분 단위가 아니라 분 단위로 나와요.**
A. 회사의 연장 인정 기준(30분 단위, 휴게 차감 등)이 정해지면 그 기준으로 계산되도록 설정합니다.
