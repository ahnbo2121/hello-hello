# 근태 대조 업무 측정 기록

지금 방식(종이 근무표 + 스케줄 변경 동의서 + 지문)으로 매일 근태를 대조하는 데 드는 시간과 오류를 **1~2주 동안** 기록합니다. 이 숫자는 [개선안](개선안-스케줄변경-전자결재.md)의 "Before" 근거로 씁니다.

> **개인정보 주의**: 이름, 사번, 시급, 급여는 적지 마세요. 건수와 시간만 적습니다.

## 기록 방법

- 매일 밤 일일근태관리 입력을 **시작할 때와 끝낼 때 시각**을 적습니다.
- 입력을 마친 뒤 아래 항목을 셉니다. 1분이면 끝납니다.
- 쉬는 날은 줄을 비워 두고 메모에 "휴무"라고 적습니다.

### 항목 설명

| 항목 | 세는 방법 |
|---|---|
| 소요 시간(분) | 대조·입력 시작부터 일마감까지 걸린 시간 |
| 근무 인원 | 그날 출근한 직원 수 (일일근태관리에서 "평일"인 줄 수) |
| 변경구분 Y | 일일근태관리에서 "변경구분"이 Y인 줄 수 |
| 지문 누락 | 근무했는데 지문 출근 또는 퇴근이 비어 있는 건수 (출근·퇴근 따로 세면 각 1건) |
| 동의서 건수 | 그날 스케줄 변경 동의서에 적힌 줄 수 |
| 시간 불일치 | 동의서 괄호 안 시간과 실제 시각 차이(변경 전→후)가 다른 건수 |
| 점장확인 공란 | 동의서에서 점장확인 칸이 비어 있는 줄 수 |
| 종이 확인 필요 | 지문만으로 판단이 안 돼서 근무표나 동의서를 다시 본 건수 |

## 기간 요약

기록을 마친 뒤 채웁니다.

| 지표 | 계산 | 값 |
|---|---|---|
| 기록한 날 수 | | |
| 하루 평균 소요 시간 | 소요(분) 합계 ÷ 기록한 날 수 | 분 |
| 한 달 환산 소요 시간 | 하루 평균 × 한 달 근무일 수 | 시간 |
| 수정 비율 | 변경구분 Y 합계 ÷ 근무 인원 합계 | % |
| 지문 누락 비율 | 지문 누락 합계 ÷ (근무 인원 합계 × 2) | % |
| 동의서 시간 불일치 비율 | 시간 불일치 합계 ÷ 동의서 건수 합계 | % |
| 점장확인 공란 비율 | 점장확인 공란 합계 ÷ 동의서 건수 합계 | % |
