# 워크스캔 출퇴근 가이드 (매장용)

> 지문 대신 **워크스캔 앱**으로 출퇴근을 찍는 방법입니다. 3분이면 익힐 수 있습니다.

| 대상 | 이 가이드에서 볼 곳 |
|---|---|
| 크루·파트타이머 | 1~3 |
| 매니저·점장 | 1~5 |

---

## 왜 바꾸나요?

- 지문이 안 찍히거나(물기·밀가루) 수기 기록과 시간이 다르면, 본사가 **매일** 두 기록을 대조해 고쳐야 합니다.
- 앱으로 찍으면 기록이 바로 남아서 **누락과 시간 불일치가 줄어듭니다.**
- 정확한 출퇴근 기록은 **내 급여와 연장수당의 근거**가 됩니다.

---

## 1. 출근할 때 (크루)

1. 매장에 도착하면 **워크스캔 앱**을 엽니다.
2. **출근** 메뉴를 누릅니다.
3. 둘 중 하나로 인증합니다.
   - **QR**: 매장에 붙어 있는 QR코드를 카메라로 찍습니다.
   - **GPS**: 위치가 매장으로 확인되면 출근 버튼을 누릅니다.
4. 화면에 **출근 시각이 표시됐는지** 꼭 확인합니다.

✅ 출근 시각이 안 보이면 → **3. 안 찍혔을 때**로 갑니다.

## 2. 퇴근할 때 (크루)

1. 마감 정리를 끝내고 **매장 안에서** 앱을 엽니다.
2. **퇴근** 메뉴 → QR 또는 GPS로 인증합니다.
3. 화면에 **퇴근 시각이 표시됐는지** 확인합니다.

⏰ 예정보다 늦게 끝났다면 퇴근 전에 **매니저에게 연장근무를 알립니다.**
(연장근무는 워크스캔 전자결재로 신청·승인합니다.)

## 3. 안 찍혔을 때 (크루)

| 증상 | 먼저 해볼 것 |
|---|---|
| 위치가 매장으로 안 잡힘 | 휴대폰 **위치(GPS) 켜기**, 앱 **위치 권한 허용** 확인 |
| QR이 안 읽힘 | 카메라 렌즈 닦기, QR에 너무 가깝지 않게 다시 찍기 |
| 앱이 안 열림·로그인 오류 | 앱 업데이트 후 다시 실행 |
| 휴대폰을 안 가져옴·배터리 없음 | **바로 매니저에게 알리기** |

**그래도 안 되면** 그날 바로 매니저에게 아래 3가지를 알립니다.
1. 이름
2. 실제 출근(퇴근) 시각
3. 안 된 이유

❌ 다음 날 몰아서 말하지 마세요. 기억이 달라지면 시간 불일치가 생깁니다.

---

## 4. 매일 확인할 것 (매니저·점장)

| 언제 | 할 일 |
|---|---|
| 오픈 후 | 출근 예정자가 모두 **앱으로 출근 기록**이 있는지 확인 |
| 마감 전 | 퇴근 기록 누락자 확인, 연장근무 신청이 들어왔는지 확인 |
| 누락이 있을 때 | 크루에게 받은 시각과 이유를 **당일** 정리해 본사에 전달 |

## 5. 처음 바꿀 때 준비 (매니저·점장)

- [ ] 매장 입구나 직원 공간에 **출퇴근 QR코드** 붙이기
- [ ] 크루 모두 워크스캔 앱 설치·로그인했는지 확인
- [ ] 첫 주는 출근 때 매니저가 옆에서 한 번씩 같이 찍어 보기
- [ ] 이 가이드 1~3을 출력해 직원 공간에 붙이기

## 자주 묻는 질문

**Q. 지문은 이제 안 찍어도 되나요?**
A. 매장마다 전환 시점이 다를 수 있습니다. 본사나 점장 안내를 따라 주세요.

**Q. 위치 정보가 계속 수집되나요?**
A. 워크스캔은 출퇴근을 인증할 때 GPS를 쓰는 방식으로 소개되어 있습니다. 자세한 수집 범위는 앱의 개인정보 처리방침에서 확인할 수 있습니다.

**Q. 기록이 잘못 찍혔어요.**
A. 직접 고치지 말고 매니저에게 실제 시각과 이유를 알려 주세요.

## 작성자 메모 (배포 전 확인)

이 가이드는 공개 자료(워크스캔 출시 보도자료, 앱스토어 소개)를 바탕으로 만든 초안입니다. 매장에 배포하기 전에 아래 항목을 실제 앱과 사내 기준으로 확인해 주세요.

- [ ] 실제 앱의 메뉴 이름과 버튼 위치 (1·2절의 "출근"·"퇴근" 메뉴 이름) → 화면 캡처로 교체
- [ ] 우리 회사에서 QR과 GPS 중 어떤 인증을 켤지
- [ ] 출퇴근 누락 시 앱 안에서 수정 요청이 되는지, 아니면 매니저에게 알리는 방식인지
- [ ] 워크스캔 출퇴근 기록이 별도 인사·급여 시스템으로 넘어가는지 (연동 여부)
- [ ] 지문 인식기와 함께 쓰는 기간이 있는지, 전환 시점
- [ ] 연장근무 신청 메뉴 이름과 승인자
