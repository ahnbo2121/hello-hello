# 링크 페이지 원본

링크로 공유하는 두 페이지의 원본 파일입니다. 링크 페이지는 claude.ai에 올라가 있고, 이 폴더는 나중에 고칠 때 쓰는 백업입니다.

| 파일 | 링크 페이지 | 내용 |
|---|---|---|
| `사례-페이지.html` | https://claude.ai/artifact/LLnyTqZ38JW79aUtDWTaFB | 포트폴리오 사례 소개 페이지 (버전 3) |
| `wireframe/project/canvas.json`, `wireframe/project/Main.dc.html` | https://claude.ai/artifact/8VcacdESZg8mKSicw4GsTw | 클릭 가능한 와이어프레임 S1~S7 (버전 5) |

## 알아 둘 점

- 두 페이지의 데이터(직원 A~G, 시각 등)는 모두 **가상**입니다. 실제 직원 정보는 들어 있지 않습니다.
- `사례-페이지.html`은 claude.ai가 앞뒤 HTML 뼈대(`<!doctype>`, `<head>` 등)를 붙여 주는 형식이라, 이 파일만 브라우저로 열면 글꼴 등이 조금 다르게 보일 수 있습니다.
- `Main.dc.html`은 claude.ai 디자인 캔버스 형식(Design Component)이라, 브라우저로 바로 열면 동작하지 않습니다. 고칠 때는 이 파일을 수정한 뒤 같은 링크 페이지에 다시 올립니다.
- 링크 페이지에서 직접 고친 내용은 이 폴더에 자동으로 반영되지 않습니다. 링크 페이지를 고쳤다면 이 폴더도 함께 갱신해 주세요.
