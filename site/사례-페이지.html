매장에서 일하며 본 종이 스케줄 변경 동의서와 밤마다 반복되는 근태 대조를 분석하고, 회사가 이미 쓰는 인사관리 앱(워크스캔)의 전자결재로 옮기는 방안과 화면을 설계했습니다.

문제

근무시간이 바뀌면, 기록은 종이 세 장과 카톡에 흩어진다

관찰연장이나 근무 변경이 생기면 스텝은 지문을 찍고, 종이 동의서에 변경 전·후 시각과 연장시간을 손으로 적고 서명합니다. 같은 내용이 근무표 손글씨와 카톡 일일보고에도 남습니다.

관찰지문 기록은 회사의 별도 인사관리 시스템에 쌓이고, 워크스캔은 근로계약 때 말고는 거의 쓰이지 않았습니다. 워크스캔은 근무 스케줄 변경과 연장근무 신청을 전자결재로 처리할 수 있다고 소개된 앱입니다.

누가 겪나

기록은 네 사람을 거쳐 올라간다

P1 스텝

두 번 기록한다

지문도 찍고 종이에도 쓴다. 마감 직후 연장시간을 직접 계산한다.

P2 인턴매니저

네 곳을 맞춘다

지문, 근무표, 동의서, 카톡을 대조해 밤마다 입력한다.

P3 슈퍼바이저

종이를 다시 뒤진다

연장 사유와 승인자를 확인하고, 매출 대비 인건비를 본다.

P4 승인자

서명할 때를 놓친다

점장 또는 인사담당자. 바쁜 영업 중 확인 칸이 비어 간다.

페르소나는 관찰한 역할을 바탕으로 만든 가상 인물입니다.

    슈퍼바이저 · 검토할 때마다
해결

종이 동의서를 워크스캔 전자결재로

제안새 시스템을 들이지 않고, 회사가 이미 계약해 쓰는 앱의 기능을 넓혀 쓰는 방안입니다. 지문과 종이 근무표는 그대로 두고, 가장 문제가 분명한 동의서부터 옮깁니다.

지금

  1. 스텝이 종이에 시각·연장시간을 적고 서명
  2. 점장 확인 칸은 자주 비어 있음
  3. 근무표와 카톡에도 같은 내용
  4. 인턴매니저가 밤에 네 곳 대조 후 수기 입력
  5. 슈퍼바이저가 종이를 다시 넘겨보며 검토

제안

  1. 스텝이 앱에서 사유를 고르고 시각 입력, 시간은 자동 계산
  2. 승인자가 알림을 받고 그 자리에서 승인, 기록이 남음
  3. 변경 내용은 앱 한 곳에만
  4. 인턴매니저는 승인 목록과 지문만 비교
  5. 슈퍼바이저는 사유·승인자를 목록으로 검토
